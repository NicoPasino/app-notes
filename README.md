# 📌 App Notas

## 📝 App Notas (móvil y web)
Esta app es un proyecto personal con la finalidad de aprender y mejorar en el desarrollo de aplicaciones móviles (android).

---

## 🚀 Funcionalidades principales:
- Ver, Buscar, Filtrar.
- Crear, Editar, Bloquear y Desbloquear notas.
- Compartir y exportar notas.
- Archivar, Marcar como favorito.
- Enviar a la papelera, Eliminar permanentemente.

---

## 🛠️ Tecnologías utilizadas:
- Lenguajes: `JavaScript`.
- Frameworks: `React Native`.
- Almacenamiento: `SQLite`.

---

## 📌 Estado del proyecto:
